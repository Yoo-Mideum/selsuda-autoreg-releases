# 자동상품등록 프로그램 (자동후불사입 용) by 셀수다 — 배포판

프로그램이 **여기서 새 버전을 확인하고, 바뀐 파일만 받아갑니다.**
수강생은 다시 깔 필요 없이 프로그램 안에서 [지금 업데이트] 한 번만 누르면 됩니다.

## 수강생이 한 번만 하는 것

프로그램 폴더의 `백엔드\config.json` 에 아래 한 줄을 넣습니다.

```json
"update_url": "https://raw.githubusercontent.com/Yoo-Mideum/selsuda-autoreg-releases/main/version.json"
```

한 번만 넣으면 그 다음부터는 프로그램이 알아서 확인합니다.

## 새 버전을 올리는 방법

소스 폴더에서 한 줄이면 됩니다.

```
python 빌드.py --payload
python 도구_업데이트_만들기.py --올리기
```

`version.json` 과 `payload` 폴더가 새로 올라갑니다. 파일마다 붙는
확인값(sha256)은 도구가 계산하므로 손으로 적을 것이 없습니다.

## 이 저장소에 있는 것

```
version.json            지금 버전과 파일 목록
payload/확장프로그램/     화면 쪽 파일
payload/백엔드/          프로그램 서버 파일
```

* 파이썬 묶음(26MB)은 여기 없습니다. 그래서 받는 양이 수백 KB 입니다.
* 키·등록기록은 여기 없습니다. 수강생 컴퓨터에만 있습니다.

## 설치파일이 필요한 때

파이썬 묶음이나 설치 구조가 바뀐 날에만 설치파일(exe)을 따로 보내시면 됩니다.
그 외에는 전부 위 방법으로 끝납니다.
