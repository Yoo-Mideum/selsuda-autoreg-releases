자동상품등록 프로그램
(자동후불사입 용) by 셀수다

처음 쓰시는 분을 위한 설명서입니다. 위에서부터 그대로 따라 하시면 됩니다.

차례
  1. 프로그램 깔기
  2. 로그인
  3. 딱 두 가지만 넣기 (AI 키 · 네이버 키)
  4. 등록되는 상태인지 확인
  5. 상품 담기 → 등록하기
  6. 등록되는 모습
  7. 못 올라간 상품 손으로 채우기
  8. 오류가 났을 때
  9. 새 버전 받기
  10. 자주 막히는 것

1프로그램 깔기

받은 설치파일을 두 번 누르면 됩니다.

  1. 자동상품등록_설치.exe 를 두 번 누릅니다.
  2. “이 앱이 변경할 수 있도록 허용하시겠어요?” 가 뜨면 예.
  3. 창에 어디까지 됐는지 보입니다. 끝날 때까지 두세요.
  4. 끝나면 바탕화면에 자동상품등록 바로가기가 생깁니다.
크롬 확장도 설치가 같이 해 줍니다. 크롬을 켜 두셨다면 한 번 껐다 켜 주세요.
설치가 막히면 창에 무엇이 / 왜 / 지금 할 일 이 그 자리에 나옵니다. 그대로 해 보시고, 안 되면 [내용 복사] 를 눌러 강사에게 그대로 보내주세요.

2로그인

크롬 오른쪽 위 🛒 를 누르면 프로그램이 열립니다.

  1. 아이디 는 본인 휴대폰 번호 입니다. (예: 010-1234-5678)
  2. 비밀번호를 넣고 로그인.
  3. 처음이시면 [처음이신가요? 가입하기] 로 가입하세요.
비밀번호를 잊으셨으면 강사에게 말씀해 주세요. 프로그램에서는 바꿀 수 없습니다.

3딱 두 가지만 넣기

처음 한 번만 넣으면 됩니다. 넣은 값은 내 컴퓨터에만 저장됩니다.

  1. 오른쪽 위 [⚙ 셋팅하기] 를 누릅니다.
  2. AI API 키 — 구글에서 받아 붙여넣고 저장.
  3. 네이버 커머스 API 키 — 애플리케이션 ID 와 시크릿을 넣고 저장.

Gemini 키 받기 ▶   네이버 커머스 API센터 ▶

네이버 API센터에서 꼭 하셔야 하는 것
[API 허용 IP] 에 지금 쓰는 인터넷 주소를 넣어야 등록이 됩니다.
그 주소는 프로그램이 알려 줍니다 — 아래 4번을 보세요.

4등록되는 상태인지 확인

로그인하면 프로그램이 알아서 확인합니다. 눌러보실 것 없습니다.

다 ✔ 이면 그냥 쓰시면 됩니다. 이 확인은 10분마다 다시 하고, AI 비용은 들지 않습니다.

하나라도 ✖ 면 등록 단추가 잠깁니다. 돈만 쓰고 등록에서 막히는 것을 미리 막는 것입니다.

네이버 로그인 ✖ 이 가장 많습니다. 빨간 칸에 지금 쓰는 인터넷 주소가 적혀 있습니다. 그 주소를 그대로 네이버 API센터 [API 허용 IP] 에 넣으시면 풀립니다.
집·회사·휴대폰 핫스팟은 주소가 서로 다릅니다. 옮기시면 다시 넣어주세요.

5상품 담기 → 등록하기

단추는 두 개뿐입니다.

  1. 네이버에서 카탈로그(가격비교) 페이지를 엽니다.
  2. 프로그램의 [➕ 이 카탈로그 담기] 를 누릅니다.
  3. 다음 상품으로 옮겨 또 담습니다. 여러 개를 이어서 담을 수 있습니다.
  4. 다 담았으면 [▶ 등록하기] 한 번.
담은 목록을 보거나 지우려면 아래 [📋 리스트업] 을 누르세요. 거기서 한 개만 바로 등록 할 수도 있습니다.
1개당 1~3분 걸립니다. 등록하는 동안 창을 닫지 마세요.

6등록되는 모습

어디까지 왔는지 눈에 보입니다. 멈춘 게 아닙니다.

1. 상품 정보 읽기카탈로그와 판매처를 읽습니다
2. 사진 불러오기원본·리뷰 사진을 받아옵니다
3. 대표이미지 만들기AI 가 대표컷을 만듭니다
4. 상세 글자 읽기내 컴퓨터가 읽습니다 (AI 비용 0원)
5. 고시정보 채우기읽은 글자로 항목을 채웁니다
6. 상세페이지 만들기AI 가 상세설명을 씁니다
7. 네이버에 등록스마트스토어에 올립니다
중간에 멈추면 그 줄이 ✖ 로 바뀝니다. 어디서 멈췄는지 바로 보입니다. 거기까지 만든 자료는 [🗂 수동입력] 에 남아, 다시 해도 AI 비용이 들지 않습니다.

7못 올라간 상품 손으로 채우기

정보가 모자라 멈춘 상품은 버려지지 않습니다.

  1. 아래 [🗂 수동입력] 을 누릅니다.
  2. 채울 상품을 고릅니다.
  3. 빨간 칸만 채웁니다. 무엇을 적는지 칸마다 예시가 있습니다.
  4. [✔ 이대로 등록].
AI 는 다시 돌지 않습니다. 이미 만들어 둔 이미지·상세를 그대로 쓰기 때문에 비용이 들지 않습니다.
지금 적을 시간이 없으면 [💾 적어만 두기] 로 두었다가 나중에 올려도 됩니다.

8오류가 났을 때

영문 오류를 외우실 필요 없습니다. 프로그램이 무엇이 / 왜 / 지금 할 일 로 알려드립니다.

  • “컴퓨터를 다시 시작해 주세요” 가 1번으로 나오면 — 그대로 하시면 대부분 풀립니다.
  • [📋 내용 복사] 를 누르면 강사에게 보낼 내용이 그대로 복사됩니다.
  • 작은 회색 글씨(영문)는 강사가 볼 내용입니다. 신경 쓰지 않으셔도 됩니다.
허용되지 않은 인터넷 주소네이버 API센터 [API 허용 IP] 에 지금 주소를 넣으세요. 주소는 화면에 적혀 있습니다.
프로그램 서버가 꺼졌습니다바탕화면의 [자동상품등록] 을 한 번 누르세요.
AI 키가 올바르지 않습니다[⚙ 셋팅하기] 에서 키를 새로 넣으세요.
반품·교환지 주소가 없습니다스마트스토어센터에서 주소를 먼저 등록하세요.
그 밖에컴퓨터를 다시 시작 → 그래도 같으면 [내용 복사] 해서 보내주세요.

9새 버전 받기

다시 깔지 않으셔도 됩니다.

  1. 새 버전이 나오면 프로그램 맨 위에 주황 칸 이 뜹니다.
  2. [⬇ 지금 업데이트] 한 번 누르면 끝입니다.
  3. 바뀐 파일만 받습니다(보통 수백 KB). 잠시 뒤 화면이 알아서 새로 고쳐집니다.
[⚙ 셋팅하기] 의 [업데이트 확인] 으로 직접 확인하실 수도 있습니다.

10자주 막히는 것

등록 단추가 눌리지 않아요 위쪽 점검에 ✖ 가 있습니다. 빨간 칸의 [지금 할 일] 을 먼저 하세요.
어제는 됐는데 오늘 안 돼요 인터넷 주소가 바뀐 경우가 많습니다. [API 허용 IP] 에 지금 주소를 다시 넣어주세요.
등록이 자꾸 끊겨요 백신이 네이버 연결을 막는 경우가 많습니다. 잠시 끄고 해 보세요.
화면이 예전 그대로예요 크롬 주소창에 chrome://extensions → 이 확장의 [새로고침].
AI 비용이 걱정돼요 상세 글자 읽기는 내 컴퓨터가 합니다(0원). [⚙ 셋팅하기] 에서 확인하실 수 있습니다.
창을 닫아 버렸어요 만들던 자료는 [🗂 수동입력] 에 남아 있습니다. 다시 해도 AI 비용이 들지 않습니다.
그래도 막히시면 [📋 내용 복사] 를 눌러 강사에게 그대로 보내주세요. 무엇이 어디서 막혔는지 전부 들어 있습니다.
